Klicke auf „Template generieren“.

Import in Zabbix: Data collection → Templates → Import. Danach Host verlinken und {$SSH.USER} sowie Key-/Passwort-Makros setzen. Child-Items entstehen automatisch über LLD, sobald das Master-JSON Daten liefert.
